Install RomP

RomP is a free app for macOS, Windows and Linux. It needs a RomM server, version 5.0 or newer, with your games on it.

What you need

  • A RomM server, version 5.0 or newer. Sending games to RomP from RomM's Install on device needs RomM 5.4.
  • Your own games and BIOS files on that server. RomP doesn't include any.
  • A Mac with Apple silicon and macOS 11 or newer, or a 64-bit Intel or AMD PC with Windows or Linux.

macOS

Download the macOS zip from the latest release, unzip it and move RomP to Applications. Release builds are signed and notarized by Apple.

Or install it with Homebrew:

brew install --cask rompemu/tap/romp

Windows

Download the Windows zip from the latest release, unzip it and open RomP. Windows builds aren't signed yet, so the first time Windows warns you: choose More info, then Run anyway.

Linux

The latest release has four downloads. Pick one:

  • AppImage: one file that runs on most distributions. Make it executable and open it.
  • .deb: for Debian, Ubuntu and their relatives.
  • .rpm: for Fedora, openSUSE and their relatives.
  • tar.gz: the app in a folder, to put wherever you like.

Connect to your RomM server

  1. Open RomP and enter your RomM server's address.
  2. Approve RomP in RomM, by scanning the code shown with your phone or opening the link. RomP never stores your password.
  3. Open a game and press Play. RomP downloads the game and the emulator it needs, and fetches BIOS files from your server's firmware.

Updates

RomP checks GitHub once a day and tells you when a new version is out. You can turn this off in Settings. With Homebrew, brew upgrade updates it.

The nightly build has the newest changes before they're released. Nightly macOS builds aren't notarized: the first time, right-click RomP and choose Open.

Where RomP keeps your files

Downloaded games, saves, save states, screenshots and settings are in ~/Library/Application Support/Romp on macOS, %LOCALAPPDATA%\Romp on Windows and ~/.local/share/Romp on Linux. Sign-in tokens are kept in your system's keychain or credential store.
